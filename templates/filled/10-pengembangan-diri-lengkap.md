## 1. MINDSET PENGEMBANGAN DIRI

### 1.1 Growth Mindset vs Fixed Mindset

| Fixed Mindset | Growth Mindset |
|---------------|----------------|
| "Aku tidak bisa" | "Aku belum bisa" |
| "Ini terlalu sulit" | "Ini tantangan menarik" |
| "Aku gagal" | "Aku belajar dari kegagalan" |
| "Mereka lebih pintar" | "Mereka inspirasi untuk belajar" |
| "Aku tidak suka feedback" | "Feedback membantu aku berkembang" |

### 1.2 Prinsip Pengembangan Diri

```
KONSEP "COMFORT ZONE":

┌─────────────────────────────────────────┐
│              PANIC ZONE                 │
│  ┌───────────────────────────────────┐  │
│  │         STRETCH ZONE              │  │
│  │  ┌─────────────────────────────┐  │  │
│  │  │       COMFORT ZONE          │  │  │
│  │  │    (Aman, Tidak Bertumbuh)  │  │  │
│  │  └─────────────────────────────┘  │  │
│  │    (Bertumbuh, Tantangan)         │  │
│  └───────────────────────────────────┘  │
│     (Stress, Shutdown)                  │
└─────────────────────────────────────────┘

TUMBUH = Keluar dari Comfort Zone
TAPI   = Jangan sampai Panic Zone
```

### 1.3 Hukum 10.000 Jam (Diperbarui)

```
PENDAPAT LAMA:
"10.000 jam untuk jadi expert"

PENDAPAT BARU:
"10.000 jam DELIBERATE PRACTICE untuk jadi expert"

Artinya:
❌ 10.000 jam mengerjakan hal yang sama
✅ 10.000 jam belajar hal baru dengan feedback

Deliberate Practice = 
- Fokus di area lemah
- Dapat feedback langsung
- Tingkat kesulitan meningkat
- Ada tujuan yang jelas
```

## 2. SOFT SKILLS

### 2.1 Komunikasi

| Aspek | Tips | Latihan |
|-------|------|---------|
| **Mendengar** | Fokus, jangan sela, tanya | Praktik active listening |
| **Berbicara** | Jelas, singkat, terstruktur | Presentasi 1x/minggu |
| **Menulis** | Terstruktur, gunakan paragraf | Tulis 1 hari 1 paragraf |
| **Non-verbal** | Kontak mata, postur tubuh | Rekam diri sendiri |

**Framework Komunikasi (STAR):**
```
S - Situation: Konteks situasi
T - Task: Tugas yang harus dilakukan
A - Action: Tindakan yang diambil
R - Result: Hasil yang didapat

Contoh:
"Saat itu tim kami menghadapi deadline (S).
 Saya ditugaskan menyelesaikan fitur utama (T).
 Saya kerja lembur dan koordinasi dengan tim (A).
 Akhirnya kami selesai tepat waktu (R)."
```

### 2.2 Kepemimpinan

**Gaya Kepemimpinan:**
| Gaya | Kapan Digunakan | Contoh |
|------|-----------------|--------|
| **Otoriter** | Krisis, butuh keputusan cepat | Darurat,deadline ketat |
| **Demokratik** | Brainstorming, kreativitas | Meeting ide |
| **Servant** | Tim butuh support | Mentoring |
| **Visioner** | Perubahan besar | Transformasi |

**Prinsip Kepemimpinan:**
1. **Servant First** — Layani tim, bukan dilayani
2. **Lead by Example** — Contohkan, jangan cuma suruh
3. **Trust** — Percaya pada tim
4. **Communicate** — Komunikasi terbuka
5. **Develop Others** — Bantu tim berkembang

### 2.3 Problem Solving

**Framework 5 Why:**
```
Masalah: Website down

Why 1: Kenapa website down?
→ Server overload

Why 2: Kenapa server overload?
→ Traffic naik tiba-tiba

Why 3: Kenapa traffic naik tiba-tiba?
→ Viral di social media

Why 4: Kenapa viral?
→ Campaign marketing sukses

Why 5: Kenapa campaign sukses?
→ Content menarik & relevan

SOLUSI:
Short-term: Scale up server
Long-term: Persiapan untuk traffic spike
```

**Framework PDCA:**
```
Plan → Do → Check → Act

PLAN: Buat rencana & hipotesis
DO: Eksekusi rencana
CHECK: Evaluasi hasil
ACT: Adjust & improve
```

### 3.2 Framework Belajar

**1. SAT Method:**
```
S - Specific: Apa yang mau dipelajari?
A - Actionable: Langkah konkret apa?
T - Timeline: Kapan selesai?

Contoh:
"Belajar SQL dalam 30 hari"
- Minggu 1: Basic queries (SELECT, WHERE, JOIN)
- Minggu 2: Intermediate (GROUP BY, Subquery)
- Minggu 3: Advanced (Window, CTE)
- Minggu 4: Project practice
```

**2. Feynman Technique:**
```
1. Pilih topik
2. Jelaskan seperti ke anak SD
3. Identifikasi yang belum paham
4. Pelajari lagi & sederhanakan
5. Ulangi sampai paham sempurna
```

**3. Spaced Repetition:**
```
Hari 1: Pelajari materi
Hari 2: Review
Hari 4: Review lagi
Hari 7: Review lagi
Hari 14: Review lagi
Hari 30: Review lagi
→ Ingat lebih lama!
```

## 5. JOB SEARCH

### 5.1 Persiapan

**Resume/CV:**
```
STRUKTUR:

1. Header
   - Nama, kontak, LinkedIn, portfolio

2. Summary
   - 2-3 kalimat: siapa Anda, keahlian, pencapaian

3. Experience
   - Posisi, perusahaan, tanggal
   - Bullet points dengan angka (achievements)
   - Gunakan action verbs

4. Skills
   - Technical skills
   - Soft skills

5. Education
   - Gelar, universitas, tahun
```

**Bullet Points yang Baik:**
```
❌ "Responsible for managing social media"
✅ "Managed social media accounts, increasing engagement by 45% in 6 months"

❌ "Handled customer complaints"
✅ "Resolved 50+ customer issues weekly, maintaining 95% satisfaction rate"

❌ "Worked on new feature"
✅ "Led development of new checkout feature, reducing cart abandonment by 30%"
```

### 5.2 Interview

**Persiapan Sebelum:**
- [ ] Riset perusahaan (mission, values, products)
- [ ] Pahami job description
- [ ] Siapkan contoh STAR (5-7 contoh)
- [ ] Persiapkan pertanyaan untuk interviewer
- [ ] Latihan dengan mirror/teman

**Pertanyaan yang Sering Ditanya:**
```
1. "Ceritakan tentang diri Anda"
   → Singkat, relevan dengan posisi

2. "Kelebihan & kekurangan Anda?"
   → Kelebihan: dengan contoh
   → Kekurangan: yang sudah di-improve

3. "Kenapa ingin bergabung?"
   → Research perusahaan, sambungkan dengan goal

4. "Ceritakan situasi sulit yang pernah dihadapi"
   → Gunakan STAR method

5. "Ada pertanyaan?"
   → Selalu tanyakan sesuatu!
```

**Pertanyaan untuk Interviewer:**
```
- "Apa tantangan terbesar untuk posisi ini?"
- "Bagaimana budaya kerja di tim ini?"
- "Apa yang diharapkan dari kandidat dalam 3 bulan pertama?"
- "Bagaimana career path di perusahaan ini?"
```

### 5.3 Negosiasi Gaji

**Framework:**
```
1. RESEARCH
   - Cek range gaji (Glassdoor, Jobstreet, LinkedIn)
   - Tanyakan ke network
   - Hitung cost of living

2. ANCHOR
   - Mulai dari angka lebih tinggi (10-20% dari target)
   - Berikan justifikasi

3. FLEXIBLE
   - Negosiasi benefit lain: bonus, remote, training
   - Jangan fokus hanya di gaji pokok

4. GRACEFUL
   - Terima atau tolak dengan profesional
```

**Script Negosiasi:**
```
"Terima kasih atas offer-nya. Saya sangat tertarik dengan posisi ini.
Berdasarkan riset saya dan pengalaman yang saya miliki, saya berharap 
gaji bisa di range [angka]. Apakah masih bisa dinegosiasi?"
```

## 7. WORK-LIFE BALANCE

### 7.1 Boundary Setting

**Aturan Batasan:**
```
WORK BOUNDARIES:
- Jam kerja: 09:00-18:00
- Email: cek 2x sehari
- Chat: jangan jawab di luar jam kerja
- Meeting: tidak ada di hari Sabtu

PERSONAL BOUNDARIES:
- Time untuk keluarga: 18:00-21:00
- Hobi: minimal 2 jam/minggu
- Exercise: minimal 3x/minggu
- Tidur: minimal 7 jam
```

### 7.2 Mencegah Burnout

**Tanda-tanda Burnout:**
1. Lelah terus-menerus
2. Sulit fokus
3. Motivasi menurun
4. Iritasi mudah
5. Isolasi sosial

**Solusi:**
1. Ambil cuti (benar-benar istirahat)
2. Delegasikan tugas
3. Komunikasi dengan atasan
4. Cari support system
5. Pertimbangkan career change jika perlu

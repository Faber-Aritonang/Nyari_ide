## 1. MINDSET KEUANGAN

### 1.1 Prinsip Dasar

```
KEKAYAAN = PENDAPATAN - PENGELUARAN - PAJAK
         = PENDAPATAN - (KEBUTUAN + KEINGINAN) - PAJAK
```

**3 Mindset yang Harus Diubah:**

| ❌ Salah | ✅ Benar |
|---------|---------|
| "Uang habis = gaji kurang" | "Uang habis = pengeluaran terlalu besar" |
| "Investasi itu ribet" | "Investasi itu wajib untuk masa depan" |
| "Utang itu normal" | "Utang itu harus dikelola" |

### 1.2 Prinsip 50-30-20

```
PENDAPATAN BERSIH (per bulan):

┌─────────────────────────────────────────┐
│ 50% → Kebutuhan (Needs)                 │
│       Rumah, makan, transport, listrik  │
├─────────────────────────────────────────┤
│ 30% → Keinginan (Wants)                 │
│       Rekreasi, shopping, hobi          │
├─────────────────────────────────────────┤
│ 20% → Tabungan & Investasi              │
│       Dana darurat, investasi, utang    │
└─────────────────────────────────────────┘
```

**Contoh untuk Gaji Rp 5.000.000:**
| Kategori | Persentase | Jumlah |
|----------|------------|--------|
| Kebutuhan | 50% | Rp 2.500.000 |
| Keinginan | 30% | Rp 1.500.000 |
| Tabungan/Investasi | 20% | Rp 1.000.000 |

## 2. MENGELOLA PENGELUARAN

### 2.1 Kebutuhan vs Keinginan

| Kebutuhan (Needs) | Keinginan (Wants) |
|-------------------|-------------------|
| Makan sehari-hari | Makan di restoran mahal |
| Transportasi kerja | Mobil baru |
| Rumah/tempat tinggal | Rumah mewah |
| Pakaian dasar | Fashion branded |
| Internet (kerja) | Netflix, Spotify |
| Asuransi kesehatan | Asuransi premium |

### 2.2 Cara Mengontrol Pengeluaran

**Metode Amplop:**
```
1. Pisahkan uang jadi 3 amplop:
   - Amplop 1: Kebutuhan (50%)
   - Amplop 2: Keinginan (30%)
   - Amplop 3: Tabungan (20%)

2. Gunakan uang dari amplop yang sesuai
3. Jika amplop habis → STOP belanja
4. Jika ada sisa → masukkan ke tabungan
```

**Metode 24 Jam:**
```
Sebelum belanja barang > Rp 500.000:
1. Tunggu 24 jam
2. Tanyakan: "Apakah ini kebutuhan atau keinginan?"
3. Jika masih ingin besok → baru beli
```

**Metode Envelope Budgeting:**
```
1. Buat budget per kategori
2. Catat setiap pengeluaran
3. Review mingguan
4. Optimasi bulanan
```

## 3. DANA DARURAT (EMERGENCY FUND)

### 3.1 Mengapa Penting

```
SCENARIO TANPA DANA DARURAT:
Pengeluaran bulanan: Rp 5.000.000
Tidak ada dana darurat
→ PHK / Sakit besar
→ Terpaksa utang kartu kredit (24%/tahun)
→ Bengkak, semakin sulit

SCENARIO DENGAN DANA DARURAT:
Pengeluaran bulanan: Rp 5.000.000
Dana darurat: Rp 15.000.000 (3 bulan)
→ PHK / Sakit besar
→ Bisa survive 3 bulan
→ Cari kerja/pengobatan tanpa tekanan
```

### 3.2 Berapa yang Dibutuhkan

| Status | Dana Darurat yang Dibutuhkan |
|--------|------------------------------|
| Karyawan tetap | 3-6 bulan pengeluaran |
| Freelancer/Wiraswasta | 6-12 bulan pengeluaran |
| Punya tanggungan | 6-12 bulan pengeluaran |
| Belum menikah | 3-6 bulan pengeluaran |

**Contoh:**
```
Pengeluaran bulanan: Rp 5.000.000
Status: Karyawan tetap, belum menikah
Dana darurat: Rp 5.000.000 × 6 = Rp 30.000.000
```

### 3.3 Cara Membangun Dana Darurat

**Langkah 1: Mulai dari yang Kecil**
```
Target: Rp 30.000.000
Cara: Tabungan Rp 1.000.000/bulan
Waktu: 30 bulan (2.5 tahun)
```

**Langkah 2: Potong Pengeluaran**
| Pengeluaran | Hemat | Per Bulan | Per Tahun |
|-------------|-------|-----------|-----------|
| Makan di luar | Kurangi 50% | Rp 300.000 | Rp 3.600.000 |
| Langganan tidak perlu | Hapus | Rp 200.000 | Rp 2.400.000 |
| Belanja impulsif | Tunda | Rp 500.000 | Rp 6.000.000 |
| **Total Hemat** | | **Rp 1.000.000** | **Rp 12.000.000** |

**Langkah 3: Simpan di Tempat yang Tepat**
| Tempat | Return | Risiko | Likuiditas |
|--------|--------|--------|------------|
| Tabungan biasa | 1-2% | Sangat rendah | Sangat tinggi |
| Deposito | 4-6% | Rendah | Rendah |
| Reksa Dana Pasar Uang | 4-6% | Rendah | Tinggi |

**Rekomendasi:** Reksa Dana Pasar Uang (return lebih tinggi, tetap likuid)

## 4. MEMBAYAR UTANG

### 4.1 Jenis Utang

| Jenis | Contoh | Bunga | Prioritas |
|-------|--------|-------|-----------|
| **Utang Konsumtif** | Kartu kredit, KTA | 18-30%/tahun | ⚠️ TINGGI |
| **Utang Produktif** | KPR, Kredit Usaha | 8-12%/tahun | ⚡ SEDANG |
| **Utang Baik** | Kredit pendidikan | 6-10%/tahun | ✅ RENDAH |

### 4.2 Strategi Membayar Utang

**Metode Avalanche (Bunga Tertinggi Dulu):**
```
1. Bayar minimum untuk semua utang
2. Sisa uang → bayar utang dengan bunga TERTINGGI
3. Setelah lunas → lanjut ke bunga tertinggi berikutnya
4. Kelebihan: Hemat bunga paling banyak
```

**Metode Snowball (Terkecil Dulu):**
```
1. Bayar minimum untuk semua utang
2. Sisa uang → bayar utang dengan nominal TERKECIL
3. Setelah lunas → bayar utang kecil berikutnya
4. Kelebihan: Motivasi karena cepat lunas
```

### 4.3 Tips Bebas Utang

1. **Jangan tambah utang baru** — Stop pakai kartu kredit
2. **Bayar lebih dari minimum** — Minimal 2x minimum
3. **Konsolidasi utang** — Gabung ke bunga lebih rendah
4. **Tambah penghasilan** — Freelance, jual barang tidak terpakai
5. **Potong pengeluaran** — Fokus bayar utang

### 5.4 Strategi Investasi

**Dollar Cost Averaging (DCA):**
```

Tanpa peduli harga naik/turun

→ Rata-rata harga lebih rendah
→ Return lebih stabil
```

## 6. PERENCANAAN KEUANGAN

### 6.1 Checklist Keuangan

- [ ] Punya rekening tabungan terpisah
- [ ] Sudah punya dana darurat (3-6 bulan)
- [ ] Tidak ada utang konsumtif (kartu kredit, KTA)
- [ ] Sudah mulai investasi
- [ ] Punya asuransi (kesehatan, jiwa)
- [ ] Punya tujuan keuangan jelas
- [ ] Rutin review keuangan bulanan
- [ ] Punya asuransi kesehatan
- [ ] Sudah planning pensiun

### 6.2 Tujuan Keuangan SMART

```
S - Specific (Spesifik)
   ❌ "Mau kaya"
   ✅ "Mau punya dana darurat Rp 30.000.000"

M - Measurable (Terukur)
   ❌ "Mau nabung banyak"
   ✅ "Nabung Rp 1.000.000/bulan"

A - Achievable (Terjangkau)
   ❌ "Nabung Rp 5.000.000/bulan (gaji Rp 5 juta)"
   ✅ "Nabung Rp 1.000.000/bulan (20% gaji)"

R - Relevan (Relevan)
   ❌ "Investasi crypto karena trending"
   ✅ "Investasi reksa dana untuk dana pensiun"

T - Time-bound (Berdasarkan Waktu)
   ❌ "Mau punya rumah"
   ✅ "Beli rumah dalam 5 tahun"
```

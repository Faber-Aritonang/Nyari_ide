## 🚀 Cara Menggunakan

### Langkah 1: Pilih Template
Pilih template yang sesuai dengan kebutuhan Anda.

### Langkah 2: Isi Template
Copy template, lalu isi bagian-bagian yang kosong `[...]`.

### Langkah 3: Simpan Sebagai File
Simpan dengan format `.txt` atau `.md`:
- `ide-bisnis-saya.txt`
- `mindmap-proyek.md`
- `action-plan-launch.md`

### Langkah 4: Upload ke Nyari_ide
1. Login ke https://nyari-ide.vercel.app
2. Buka menu **Documents** 📚
3. Upload file yang sudah diisi

### Langkah 5: Gunakan di Chat
Setelah upload, AI akan otomatis mengingat isi dokumen Anda!

---

## 💡 Tips Mengisi Template

1. **Isi semua bagian** — Semakin lengkap, semakin baik AI memahami ide Anda
2. **Gunakan poin-poin** — Lebih mudah di-chunk oleh RAG
3. **Contoh konkret** — Hindari terlalu abstrak
4. **Update berkala** — Upload versi terbaru saat ide berkembang
